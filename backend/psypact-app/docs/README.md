# PSYPACT technical notes

PSYPACT does not accept license records uploaded by member jurisdictions. There is no state license API and no
bulk license upload.

Features kept from Cosmetology and Compact Connect, and the files they were copied from, are listed in
[preserved features](./preserved-features.md).
